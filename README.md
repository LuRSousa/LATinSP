## LATinSP - Mapa Interativo da Cultura Latina

Este projeto é o meu **Trabalho de Conclusão de Curso (TCC)**. Trata-se de uma plataforma Fullstack completa que mapeia a gastronomia latino-americana em São Paulo. O sistema integra uma interface interativa e design responsivo com um backend robusto para conectar usuários à diversidade cultural latina.

### Objetivo
Combater a falta de identificação cultural entre brasileiros e suas raízes latinas, oferecendo uma ferramenta que facilita a descoberta de restaurantes latinos através de um mapa interativo e filtros inteligentes.

### Stack Tecnológica
* **Frontend:** HTML5, SCSS, JavaScript (ES6+)
* **Backend:** PHP (Arquitetura MVC)
* **Banco de Dados:** MySQL (Relações complexas)
* **APIs:** Leaflet.js (Funcionalidade principal de mapa)
* **Comunicação Assíncrona:** API REST própria em PHP (integração Frontend/Backend)
* **Deploy:** InfinityFree

### Funcionalidades Principais
* **Mapa Interativo:** Visualização geográfica com markers customizados por país.
* **Sistema de Cards:** Informações detalhadas em dois níveis (miniCard e bigCard).
* **Filtros Inteligentes:** Busca por país, preço, avaliação e tags.
* **Horários em Tempo Real:** Verificação automática de status (Aberto/Fechado).
* **Acessibilidade:** Implementação de ARIA labels e navegação por teclado.

### Arquitetura do Sistema
O projeto segue o padrão **MVC (Model-View-Controller)**, garantindo uma separação clara entre a interface do usuário, a lógica de negócio e o gerenciamento de dados assíncronos via PHP.
